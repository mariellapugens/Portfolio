# 🌸 Portfólio Pessoal | Mariella Pugens

Um portfólio pessoal desenvolvido para apresentar minha trajetória profissional, certificações, tecnologias, experiências e visão sobre desenvolvimento de software.

O projeto foi construído utilizando HTML, CSS e JavaScript, com foco em organização de código, acessibilidade, semântica e boas práticas de desenvolvimento Front-End.

Além de funcionar como um portfólio, este projeto também serve como material de estudo para alunos que desejam compreender a estrutura de uma aplicação web estática moderna.

---

## 📖 Sobre o Projeto

Este portfólio apresenta informações profissionais de forma objetiva e organizada por seções.

Durante a construção do projeto, algumas decisões foram tomadas para preservar a confidencialidade de soluções corporativas desenvolvidas ao longo da carreira. Por esse motivo, a seção de experiências destaca desafios, tecnologias e áreas de atuação em vez de expor projetos ou clientes protegidos por acordos de confidencialidade (NDA).

O objetivo é demonstrar competências técnicas, capacidade de resolução de problemas e experiência profissional sem comprometer informações sigilosas.

---

## 🎯 Objetivos

- Apresentar trajetória profissional;
- Disponibilizar currículo para download;
- Exibir certificações e tecnologias;
- Demonstrar conhecimentos em Front-End;
- Compartilhar experiências e aprendizados;
- Servir como exemplo para estudantes de desenvolvimento web;
- Aplicar boas práticas de HTML, CSS e JavaScript.
